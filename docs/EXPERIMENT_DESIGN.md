# RR-QPSO 公平比較實驗設計 v1

目的：在可負擔的計算成本內，對「RR-QPSO 相對於既有方法的效果」做出**統計上站得住**的陳述 —— 不論該陳述是「更好」、「相當」還是「更差」。

---

## 0. 先講結論：這個設計要能回答三件事

| 編號 | 問題 | 統計工具 |
|---|---|---|
| **H1（主要）** | RR-QPSO 是否優於原版 QPSO？ | 配對 Wilcoxon signed-rank，單一預先註冊假設，α=0.05 不校正 |
| **H2（主要）** | 若無差異，能否**證明**兩者實質等價？ | TOST 等價檢定，margin δ=0.01 |
| **H3（次要）** | RR-QPSO 的哪些組件有貢獻、哪些有害？ | OFAT 消融 + Friedman/Nemenyi |

**H2 很重要。** 目前數據顯示 QPSO 略優但不顯著 —— 這種情況下「沒有顯著差異」不等於「兩者相同」。TOST 才能把「實質等價」做成一個**正面結論**而不是失敗。

---

## 1. 核心設計：配對區塊（paired blocking）

### 問題
現行設計中，每個演算法各自抽獨立的最適化 seed，取樣 seed 固定為 0。這造成：
- 比較是非配對的 → 檢定力低
- 全部結果建立在單一 shot 序列上 → 可被質疑

### 做法
**讓區塊編號 `i` 同時決定最適化 seed 與取樣 seed。**

```
區塊 i：  --seed i  --shot_seed i
```

於是：
- **區塊內**：所有演算法面對**完全相同**的目標函數實現（同一條 shot 序列）
  → 可做配對比較，區塊間的難易度差異被消掉
- **區塊間**：shot 序列不同
  → 結論不再綁定單一亂數流，直接消滅「winner's curse／固定 RNG」的質疑

這一步不增加任何成本，純粹是把已有的隨機性用對地方。

### 為什麼這比「多加 seed」更有效
配對後檢定的是「每個區塊內的差值」，而非兩組的絕對值。若區塊效應（不同 shot 序列的難易度）佔總變異的一部分，配對就把那部分從誤差項移除。以目前 σ(shot)≈0.006、σ(optimizer)≈0.010 估計，變異可降約 20-30%，等效於多 5-8 個 seed。

## 2. 規格

### 2.1 預算：2,000 次評估（而非 9,664）

**理由**：排序在兩個預算下完全一致。

| 預算 | 排序 |
|---|---|
| 2,000 | QPSO > CMA-ES > RR-QPSO > DE > BO > BatchBO > SPSA > Sobol |
| 9,664 | QPSO > CMA-ES > RR-QPSO > DE > SPSA > BatchBO > Sobol |

（唯一變動是 SPSA 與 BatchBO 互換，兩者本來就接近。）

2,000 預算的成本只有 1/4.8，**省下的算力全部換成 seed 數** —— 這是提升結論可信度最划算的交換。

論文可另外附一組 9,664 的小樣本（n=5，已有）作為「完整預算下趨勢一致」的佐證。

### 2.2 區塊數：25

依事後功效分析：d≈0.87 → 80% 檢定力需 n≈21；無母數再加 15% → **24**。取 **25** 留餘裕。

### 2.3 比較對象

**第一階段（H1/H2）—— 只比兩個**
```
qpso     × 25 blocks
rr_qpso  × 25 blocks
```
把全部檢定力集中在主要假設上，不稀釋於 28 組比較。

**第二階段（H3）—— 消融**
`AESOQPSOOptimizer` 已把各組件開關暴露為參數，實作成本低：

| 配置 | 說明 |
|---|---|
| `qpso` | 基準（無任何增強） |
| `rr_full` | 完整 RR-QPSO |
| `rr_no_sobol` | 關掉 Sobol 初始化 |
| `rr_no_obl` | 關掉 OBL Phase 0 |
| `rr_no_ae` | 關掉 AE-QTS 有符號 mbest |
| `rr_no_vu` | 關掉 V-U 解耦 mbest |

OFAT（一次關一個）而非全因子 —— 全因子 2⁴=16 種配置成本太高，且交互作用不是目前的核心問題。

### 2.4 評估指標

**不要只報最終最佳值。** 三個層次：

1. **固定預算（fixed-budget）**：在 250 / 500 / 1000 / 2000 次評估時的 best-so-far
2. **固定目標（fixed-target）**：達到 V×U ≥ {0.70, 0.75, 0.80} 所需的評估次數（未達記為 censored）
3. **收斂曲線下面積（AUC）**：整體 anytime 表現，對「早期快但後期停滯」與「早期慢但後期強」有區辨力

固定目標分析是黑箱最佳化 benchmark 的標準做法（COCO/BBOB），比單一終點值資訊量大得多。

### 2.5 每個報告值都要做取樣不確定性修正

**已知問題**：報告值是「N 次帶雜訊評估中的最大值」，實測高估 +0.011 ~ +0.027（z=+2.9~3.8）。

**做法**：每個 run 的 best_params 再以 **k=20 個取樣種子**重新評估，報告
```
期望 V×U ± 95% CI（k=20）
```
而非原始最大值。工具已存在：`benchmark/shot_seed_test.py`。

## 3. 統計分析計畫（分析前先寫定，不事後調整）

### H1：RR-QPSO vs QPSO
- **檢定**：Wilcoxon signed-rank（配對，雙尾），對 25 個區塊的差值
- **α = 0.05，不做多重比較校正**（僅此一個預先註冊的主要假設）
- **效果量**：配對 Cliff's delta + 差值的 bootstrap 95% CI
- **報告**：中位數差值、CI、p、效果量，缺一不可

### H2：等價性（TOST）
- **等價界限 δ = 0.01**（V×U 的實質意義門檻；小於此差異在化學上無意義）
- 兩個單尾檢定；**兩者皆 p<0.05 才能宣稱等價**
- 若 H1 不顯著且 H2 顯著 → 結論是「**實質等價**」，這是正面結論
- 若兩者皆不顯著 → 結論是「**證據不足**」，誠實承認

### H3：消融
- **Friedman 檢定**（多組配對，無母數）判斷 6 種配置是否有整體差異
- 顯著則做 **Nemenyi 事後檢定**，畫 critical difference 圖
- 這是多演算法比較的標準做法（Demšar 2006），比 28 組兩兩 t 檢定合理得多

### 預先註冊
在跑之前，把上述三段寫進 `PREREGISTRATION.md` 並 git commit。分析時不得更改。這能擋住「換個指標就顯著了」的誘惑，也是投稿時的加分項。

## 4. 成本

實測整座叢集吞吐量 **≈ 1.0 evals/s**（322,000 次評估 / 3.86 天）。

| 階段 | 配置數 | 區塊 | 預算 | 總評估 | 時間 |
|---|---|---|---|---|---|
| 第一階段 H1/H2 | 2 | 25 | 2,000 | 100,000 | **~28 小時** |
| 第二階段 H3 消融 | 6 | 25 | 2,000 | 300,000 | **~83 小時** |
| 取樣修正 | — | — | — | 50 runs × 20 | ~30 分鐘 |

第一階段 **一天多**就能給出主要結論。第二階段可視第一階段結果再決定是否投入。

## 5. 需要的程式改動

都很小：

1. **`run_experiment.py`**：`--shot_seed` 已存在，只需在 launcher 把它綁到區塊編號
2. **`benchmark/launch_benchmark.py`**：新增 `--paired_blocks`，令 `seed == shot_seed == block`
3. **`optimizers/qpso.py`**：`RRQPSO` 加 `--ablate {none,sobol,obl,ae,vu}`，對應關閉 `AESOQPSOOptimizer` 的既有旗標
4. **`benchmark/stats_test.py`**：加入 Wilcoxon signed-rank、TOST、Friedman/Nemenyi、fixed-target 分析

## 6. 這個設計的誠實之處

它**沒有預設 RR-QPSO 會贏**。三種結局都能給出可發表的陳述：

| 結局 | 論文怎麼寫 |
|---|---|
| RR-QPSO 顯著較優 | 主張成立，有配對檢定與效果量支撐 |
| 實質等價（TOST 顯著） | 「RR-QPSO 與 QPSO 表現相當，但變異更小／某組件有獨立價值」 |
| QPSO 顯著較優 | 誠實報告，並用消融指出哪個組件造成退步 —— 這仍是有價值的負面結果 |

目前數據（d≈0.87 偏向 QPSO）讓第三種結局的機率不低。**建議先接受這個可能性，再決定論文的定位** —— 與其讓審稿人發現，不如自己先做完整的消融並解釋清楚。
